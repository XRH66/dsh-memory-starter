## 0.4.0 有什么

- **按对话开启**：默认不读不记；在设置页给对话打开记忆，从下一新回合起保存双方原话。可选「新对话自动开启记忆」。
- **原话由程序保存**：存进本地 SQLite，建全文索引；撤回的消息会从全文索引删除。
- **按需检索**：回答前不自动注入记忆，由模型调用 `memory_search`（检索）、`memory_open`（展开原文）、`memory_recent`（最近记录）。检索结果精简为短编号，每次最多 10 条、约 1024 词元；开启记忆的回合附带 7 条回答规则（查不到就说不知道、只复述记录里的时间等）。
- **后台整理**：空闲时合批整理成十二类条目写进 Vault（Markdown，可用 Obsidian 打开修改）。整理默认用低推理档位。
- **遗忘曲线**：事实、关系、偏好、习惯 365 天；目标、约定、看法、感想 90 天；事件、计划、待办、近况 30 天；重要度高的翻倍。衰减只降排序，用户淡化过的才排除；再次确认会恢复。
- **短期接续**：换对话或换模型时带上其他对话最近的原文，同一对话只留一条，没有新内容不注入。DSH 压缩上下文后会按需要重新注入。
- **向量检索（可选）**：本地 Qwen3-Embedding 0.6B／4B／8B、BGE，或 OpenAI 兼容接口；可选重排（默认关）。回答前检索有 1.3 秒时限，在线服务结果不确定时暂停 5 分钟后自动恢复。
- **设置页**：首次只有一个配置页（填新目录、选整理模型、勾选对话、启用、重启）；之后是「记忆／检索模型／状态／维护」四页。状态页有索引进度、最近 20 次检索耗时、各服务的连接测试；维护页可「选择此记忆库」切换到另一个已有库（下次启动生效）。
- **时区**：默认北京时间，可从列表改选。

0.4.0 去掉了：Basic Memory 及其连接、QQBridge 接入、unified 模式、legacy 入口、回答前自动注入链、纯净模式插件和第三方 Agent 经 Basic Memory 共享记忆的路线。

## 日常部署

| 项目 | 现状 |
| --- | --- |
| DSH | 0.2.1-rc.5，web 档案，端口 3080 |
| 加载的快照 | `.local/runtime/versions/memory-nowarn-20261111-142039`（提交 `8c587c6`） |
| 回退 | 把 `~/.dsh/profiles/web/cordis.patch.yml` 中记忆插件的路径改回 `memory-converge-20261111-124309`，或直接恢复备份 `cordis.patch.yml.bak-20261111-nowarn`，再重启 |
| 部署配置 | `.local/runtime/daily-deployment.json`（含凭据，不要整份打印） |
| 检索模型 | 硅基流动自定义接口 `BAAI/bge-m3`（用户主用这套，不再追 4B／8B） |

**部署新版本的做法**：

1. 按白名单导出快照：`node .local/automation/export-release.cjs . .local/runtime/versions/memory-<名字>-<UTC 时间>`；
2. 备份 `cordis.patch.yml` 为 `*.bak-<日期>-<名字>`，把记忆插件那一行（`name: 'file:///…/lib/bundle-entry.js'`）改指新快照；
3. 用 `.local/automation/restart-dsh.ps1` 重启（会打断正在进行的对话）；
4. 核对插件已加载、设置页正常。

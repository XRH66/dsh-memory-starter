## 已验证的行为

- 原话按用户和助手消息分别保存，正文提交不等待向量；
- 全文检索、`memory_open`、`memory_recent` 和短期接续从原话库读取；
- 向量按模型档案保存，切换模型不自动删除旧档案；
- 重排失败时保留原顺序；
- 搜索已经取得结果后超时，可以返回部分结果；
- 宿主卡顿从检索计时中扣除，每个计时器最多补 10 秒；
- 导入旧笔记时 `check` 只读，`apply` 先备份并按批写入；
- 「维护 → 删除原话」能把单条原话标为撤回，并让全文和向量侧跳过；
- 设置页已能管理对话开关、模型服务、索引、重排、时区、记忆库和手选资料。

## 没有验证或没有完成用户验收

- 没有 Linux 实机验收；当前实际部署记录是 Windows。
- 没有 macOS 实机验收。
- 本地模型的一键下载、Python 复用和后续启用没有在另一台干净机器完成全流程。
- 真实用户在场删除原话后的长期使用体验还没有专项验收。
- 没有公网、多用户、群聊隔离或跨机器同步验证。
- 旧笔记界面导入尚未实现，只有命令行入口。
- 原话库浏览、前后说法可视化对照和只读设置页尚未实现。
- 单次 P01 不能代表长期准确率；模型、服务线路和宿主插件状态都会影响结果。

## 发布前检查

每次发布前在最终提交上执行：

```powershell
npm test
npm run links
npm run release:check
node scripts/check-release-export.mjs --validate-only
git diff --check
```

发布环境还会对实际工作树运行隐私检查；这项检查和本机的私有环境变量不会随公开包分发。

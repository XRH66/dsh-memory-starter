改动后的 `beforeBackground` 完整代码：

```js
async function beforeBackground({signal}={}){
  while(foreground||!canRun()){
    shutdown.signal.throwIfAborted();signal?.throwIfAborted();
    await delay(10,undefined,{signal:AbortSignal.any([signal,shutdown.signal].filter(Boolean))});
  }
  signal?.throwIfAborted();
  // setTimeout(0) waits for a clock tick (~15 ms on Windows), which adds up
  // across background passes. setImmediate drains arrived I/O first without that wait.
  await nextTurn(undefined,{signal:AbortSignal.any([signal,shutdown.signal].filter(Boolean))});
}
```

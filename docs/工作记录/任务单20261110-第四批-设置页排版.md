## 动手前先对齐 DSH 本身的样式

本页嵌在 DSH 设置窗口里（左侧是账号与余额、通用设置、模型等）。先看 DSH 自带设置页的写法：分组是用边框卡片还是标题加分隔线、开关和按钮长什么样、用哪些 CSS 变量。下面的 `Card`、`Switch`、`Badge` 外观以 DSH 自带页面为准，宁可朴素一点也要跟宿主一致，不自创一套风格。能从 DSH 安装目录读到它的样式变量就照用；读不到就请用户截一张「通用设置」页。

### 已查到的 DSH 自带样式（dsh-web-frontend 的打包 CSS，2026-11-10）

DSH 设置页**不用边框卡片**，是一列“字段”，字段之间用 0.5px 细线分隔。下面组件照此实现，覆盖后文“卡片有细边框和圆角”的设想：

- 字段：`display:flex;flex-direction:column;gap:6px;padding:12px 0`；相邻字段 `border-top:.5px solid var(--dsw-alias-border-l2)`。
- 字段头：标签 13px、字重 500、`--dsw-alias-label-primary`；右侧 24×24 的「?」按钮（`aria-expanded`，悬停底色 `--dsw-alias-bg-layer-4`），点开后下方出现 12px、行高 1.6、`--dsw-alias-label-secondary` 的说明。
- 输入框：高 34px，`padding:0 12px`，`.5px solid var(--dsw-alias-border-l4)`，圆角 `--dsw-radius-md`，底色 `--dsw-alias-bg-layer-3`，13px；聚焦边框 `--dsw-alias-state-business-primary`；出错边框 `--dsw-alias-state-error-primary`。
- 提示：12px、行高 1.5、`--dsw-alias-label-tertiary`。
- 开关：36×20 圆角胶囊，关 `--dsw-alias-border-l3`，开 `--dsw-alias-brand-primary`；滑块 16px，关时 `--dsw-alias-switch-thumb`，开时 `--dsw-alias-label-primary-foreground`，开时右移 16px；`role=switch` + `aria-checked`。
- 按钮：圆角 `--dsw-radius-md`，14px，`padding:0 14px`，高 36px（小号 28px/12px）；主按钮底色 `--dsw-alias-button-primary-fill`、字色 `--dsw-alias-label-primary-foreground`、悬停 `--dsw-alias-button-primary-hover`；次按钮透明底，悬停 `--dsw-alias-interactive-bg-hover`；禁用 `opacity:.4`。
- 状态标记：高 28px（我们用小一点的 22px），12px、字重 500，圆角 `--dsw-radius-sm`；成功底色 `--dsw-alias-state-success-tertiary` 字色 `--dsw-alias-state-success-primary`；警告底色 `--dsw-alias-state-warn-tertiary` 字色 `--dsw-alias-state-warn-label`；错误字色 `--dsw-alias-state-error-primary`；空闲 `--dsw-alias-state-idle-primary`。
- 勾选确认：复选框 16px，`accent-color:var(--dsw-alias-button-primary-fill)`。
- 每个变量都要写系统色兜底（如 `var(--dsw-alias-border-l2,ButtonBorder)`），保证插件单独渲染时也能看。

于是“卡片”实现为“分组”：分组标题（15px、字重 600）+ 若干字段 + 分组底部的操作栏；分组之间留 24px 空白，不加外框。

## 全局规则（先做公共组件，再逐页套用）

在 `lib/client.js` 里新增几个小组件，全页统一使用：

- **`Card({title, badge, hint, actions, children})`**：一块设置。标题行左边是标题，紧跟可选状态标记和「?」；底部是操作栏，按钮靠右，主按钮在最右。卡片之间间距 16px，卡片有细边框和圆角（用 DSH 现有 `--dsw-alias-border-l2` 等变量，没有就用系统色兜底，照文件开头 CSS 的写法）。
- **`Field({label, hint, children})`**：一行表单。标签固定宽度（约 8em，次要文字色）在左，控件在右并占满剩余宽度（最大约 28em）；可选的一行灰色小字提示在控件下方。标签与控件间距 12px，行间距 12px。宽度小于 520px 时标签移到控件上方。**所有输入框、下拉框都必须放在 Field 里**，宽度统一。
- **`Badge({tone, children})`**：状态标记，带小圆点的短词。`ok`（绿：已加载、已就绪、使用中）、`warn`（琥珀：需重启、待生效、建索引中）、`off`（灰：已关闭、未建索引）、`error`（红：失败、不可用）。
- **`Hint({text})`**：标题或标签旁的「?」小按钮，`title` 与 `aria-label` 都是完整说明；点击时在下方展开这段说明，再点收起。原先的长解释都搬进这里。
- **`Switch`**：开关样式的复选框（仍是 `<input type=checkbox role=switch>`，只改外观），用于所有“开/关”类选项。
- **操作反馈**：保存或操作后的提示放在该卡片操作栏左侧的一行小字里；成功提示 6 秒后自动消失，错误提示保留到下一次操作。不再在页面里留一整段“操作回执”。
- **禁用按钮**：给 `title` 写明原因（如“请先勾选云端确认”“没有修改”）。

文字规则：

- 页面上常驻的说明句子每条不超过 30 个汉字；超过的改写或搬进 `Hint`。
- 状态一律用 `Badge` 或“名称 — 数值”行，不写成句子。
- 不显示内部标识（档位 id、`custom-api` 这类），显示给人看的名字（如“自定义 API · BAAI/bge-m3”）。
- 删除页面副标题“选择要记住的对话和检索模型；其余在「维护」里”。

## 逐页改法

### 记忆

- 卡片「记忆框架」：标题旁 `Badge`（已加载 / 未加载 / 需重新加载）。原“已保存；部分对话等待下一新回合生效”改为 `Badge warn`“部分待生效”，说明放 `Hint`。
- 卡片「对话」：
  - 第一行 `Switch`“新对话自动开启记忆”，说明放 `Hint`。“只有开启的对话会被记住……”整句移进卡片标题的 `Hint`。
  - 搜索框保持。
  - 列表每行：左边标题 + 下面小字工作区；右边一个 `Switch` 表示是否记忆，点击即调用原来“启用/关闭本对话记忆”的同一接口。去掉“已关闭：不读不记”文字和大按钮。
  - 左侧勾选框：先读代码确认用途。若用于批量操作，保留，并在列表上方出现“已选 N 项”与批量按钮；若没有实际用途，删除。回执里写明是哪种。
- 卡片「记忆功能」：四个 `Switch`，每个的长说明放 `Hint`；卡片说明句删掉（放标题 `Hint`）。保存方式不变。
- 卡片「时区」：`Field` “个人时区”输入框，占位 `Asia/Shanghai`；标题旁 `Badge` 显示当前生效时区；“本机时区 …；留空使用北京时间”放 `Hint`。保存按钮进操作栏。
- 卡片「短期接续」：`Field` “注入长度”下拉；“K = 1024 tokens……”与用途说明放 `Hint`。保存按钮进操作栏。

### 检索模型（含第三批补的「向量」「重排」子选项卡）

- 「向量」子选项卡：
  - 卡片「当前模型」：`Field` “模型”下拉；下拉下方一行短提示（如“云端 · 按量计费”“本地 · 占用约 X 内存”）；标题旁 `Badge`“使用中”或“重启后切换”。删掉选项文字里重复的“（当前使用）”以外的长说明，长说明进 `Hint`。
  - 卡片「已保存的服务」：把“新建服务…”下拉改为**列表**，每行：名称、主机名 · 模型 · 维数、`Badge`“使用中”（如是）、右侧小按钮「编辑」「删除」（使用中的删除按钮禁用并有 `title` 原因）。列表下方「+ 新建服务」按钮。
  - 点「编辑」或「+ 新建服务」后，在列表下方展开表单（`Field`：名称、API 地址、模型名称、向量维数、API Key），**操作栏在表单底部**：「取消」「保存服务」。“填写任意兼容 OpenAI 向量接口……需为 https”进 API 地址的 `Field` 提示（一行）。
  - 云端确认勾选放在最终保存按钮正上方，文字缩为“我知道检索内容会发送到云端并计费”；“保存并重启后会自动建索引……”进 `Hint`。
  - 底部操作栏：主按钮「保存」（切换模型），次按钮「只存入列表」；禁用时 `title` 说明原因。
- 「重排」子选项卡：同样用 `Card` + `Field` + `Badge`，确认勾选与操作栏位置与「向量」一致。

### 状态

- 卡片「运行状态」，标题行右侧一个「刷新」按钮（合并原“刷新状态”和“刷新运行状态”，点击同时调用两者原来的刷新）。内容为名称—数值行：
  - 记忆服务 — `Badge`
  - 待同步 — N 项
  - 当前模型 — 人能读的名字 + `Badge`（已加载/未加载）
  - 索引 — 进度条（完成数/总数）+ `Badge`（已就绪/建索引中/未建立）
  - 用量 — “285 次 · 13,942 tokens”（千分位）；“未知用量”只在大于 0 时显示
  - 重排 — 第三批的状态，同样格式
  - 长期整理 — `Badge`（空闲/等待调度/运行中）+ 小字“待处理 0 · 运行中 0 · 已完成 0”；“持有”和“已整理待投递”只在大于 0 时显示，并用 `Hint` 解释含义
- 删除“统一向量服务已接入；当前生效档位：…”“加载与索引就绪分别计算”“后台操作仍检查原始授权……”“操作回执……”这些句子；必要含义进 `Hint`，操作结果走操作反馈。
- 卡片「操作」：「准备索引」（索引已就绪时为次要样式；会产生费用时按钮旁 `Hint` 说明）、「恢复后台任务」、「尝试整理待办」。

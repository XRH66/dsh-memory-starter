# 回执：新对话自动开启记忆（第一段）

日期：2026-11-10

范围：只完成任务单第一段的实现、测试与回执；未执行快照、部署配置切换、DSH 重启或第二段其他操作。

## 改动文件

- `lib/session-memory.js`：新增 `enabledSessionIds()` 和 `autoEnable(agent)`。自动开启只接受当前主机登记的全新根会话，要求控制器未关闭、会话 ID 合法、无运行时父会话、无继承事件、回合数和用户消息均为零，且持久授权中尚无该会话记录；满足后等待 `policy.set(id,true)` 写入并刷新已保存状态，任何条件或异常均返回 `false`。
- `lib/platform-host.js`：加入运行期 `autoEnableNewSessions` 开关；`agent/created` 监听器在自动开启时等待授权写盘，异常只记录警告且不影响会话创建；设置状态和 `replace` 计算使用“旧选择 + 当前已开启会话”的并集；设置回执增加 `autoEnableNew`；新增 `afterSessionDefaultSave`，保存后更新运行期开关、静态指纹、配置指纹和 applied 状态。
- `lib/deployment-config.js`：新增 `stageDeploymentSessionDefault()`，沿用配置锁、revision 校验、原子保存和 `afterSave` 流程；校验顶层布尔字段；设置读取结果增加 `autoEnableNewSessions`；`unbind` 对其他入口自动开启、但不在旧 `dshSessionIds` 中的合法会话改为无操作关闭兼容，非法会话 ID 仍拒绝。
- `lib/bundle-entry.js`：启动 portable 时把 `autoEnableNewSessions` 从部署配置传给个人宿主。
- `lib/settings-host.js`：新增 `POST /session-default`，成功保存后重新读取部署设置，返回与 `/sessions` 一致的会话回执；缺少对话记忆控制器或保存回调时返回 404。
- `lib/client.js`：在“记忆 → 对话”说明后增加“新对话自动开启记忆”复选框及说明；仅在新设置回执提供 `autoEnableNew` 布尔能力标识时显示；保存走专用路由，期间禁用控件，成功更新会话回执与已选会话，失败进入现有对话提示。既有 `ModelPicker` 未提交修复保持原样。
- `test/session-memory-auto-enable.test.js`：新增控制器、host、配置暂存、设置信息并集、关闭路径和 HTTP 路由测试。
- `test/portable-session-memory-ui.test.js`：新增复选框显示、请求体、请求头、保存期间禁用和成功后状态更新测试。
- `release-files.json`：把新增测试文件加入发行白名单。

`test/portable-memory-runtime-ui.test.js` 中已有的未提交修复未改写；本轮只读取并核对其写法。`lib/client.js` 中已有的 `ModelPicker` 修复也保持不变。

## 偏离与风险

# 回执 2026-11-15-H：助手原话降权与配对

## 结果

已完成助手原话降权、同会话同回合配对和自动预取过滤。

- 搜索结果最终排序时，`kind === 'original' && role === 'assistant'` 的 rank 乘以 `ASSISTANT_RANK_WEIGHT = 0.5`；旧笔记的 `SUMMARY_RERANK_WEIGHT = 0.7` 保持不变。
- 同一搜索包含同会话、同回合的用户原话和助手原话时，助手行不再单独输出，改为在用户行内带 `助手当时回复`。
- 助手回复取原话正文，按 Unicode 字符截到 120 字；超长时末尾加 `…`，模型看到的字段总长为 121 个字符。
- 同回合有多条助手原话时，取最终 rank 最高的一条；其余同回合助手行不单独占结果。
- 用户行保留原 `ref`、`anchor`、`label` 和 `text`，排名取用户与所选助手中较高者。
- 用户未命中或来源校验失败时不配对；助手单独出现时仍按新权重降权。
- 自动预取跳过单独的助手原话，用户行上的配对回复不写入预取行；`selectPrefetch().stats.assistantSkipped` 记录被跳过的单独助手记录数。
- `memory_open` 展开用户原话时仍照旧带出同回合邻近消息，不再次套用配对折叠。

## 改动位置与配对层级

### `lib/memory-query.js`

- 导出常量 `ASSISTANT_RANK_WEIGHT = 0.5`。
- 在重排完成后的最终加权处应用助手降权，和旧笔记 `SUMMARY_RERANK_WEIGHT` 位于同一阶段。
- `selectPrefetch` 在生成候选行之前过滤单独助手原话，并把数量写入 `assistantSkipped`。
- 配对放在 `validateResult` 中，位于原有 `current()` 逐条来源校验之后、`search-session` 打包之前。

选择这一层的原因：

1. 助手记录已经和独立出现时一样通过同一套 `current()` 校验，校验失败会直接从结果中移除，不会挂载。
2. 此时最终 rank 已包含全文、向量融合和重排结果，可直接实现“取最高助手、用户取较高 rank”。
3. 仍在 `fit` 和 `modelRecord` 之前，后续 token 预算按实际模型可见字段计算，不会为已折叠的助手行重复计费。
4. 配对只对带 `query` 的搜索请求生效；`memory_open` 和 `memory_recent` 不经过这一步，展开邻居行为不变。
5. 向量结果没有 `source.sessionId/source.turn` 时，通过 `anchor.ref` 回查原话库后再分组；取不到来源或缺少 `anchor.ref` 时不配对。

### `lib/suzu/search-session.js`

- `fit` 保留内部字段 `assistantReply`。
- `modelRecord` 把内部字段输出为模型可见键 `助手当时回复`。
- 其他记录字段、ref、预算计量和 `memory_open` 逻辑未改。

### `lib/index.js`

- 预取空统计增加 `assistantSkipped: 0`。
- `recordSearch` 的预取记录带上 `assistantSkipped` 计数。

## 风险与取舍

1. 用户问“你上次回答过什么”这类问题时，自动预取不会再单独带助手原话，模型需要自己调用 `memory_search`。这是本任务选择“预取只放用户的话”的直接结果。
2. 助手原话仍可在 `memory_search` 中单独搜到，但 rank 为原来的 0.5；它能保留历史上下文，但不再和用户事实同权。
3. 回复截断按 Unicode 字符而非 UTF-16 长度计算，避免拆开 emoji 或其他代理对。
4. 配对信息只出现在搜索结果的模型可见记录中，不改变存储、向量索引、编码、标签文字、工具描述、回答规则或预取门槛。
5. 本批未运行真实模型、基准、真实记忆库或 DSH 部署验证；验收范围是本地单元和集成测试。

## 发现

1. 同一会话同一回合若出现多条用户原话，任务单没有规定唯一挂载目标。当前实现挂到 rank 最高的用户行，并移除该回合所有单独助手行。现有保存链路通常每回合只有一条直接用户消息，因此该边界未影响本次测试。
2. 旧实现遇到缺少 `anchor.ref` 的原始记录会在来源校验中抛成 `BACKEND`。本批在同一来源解析处改为“取不到来源就不配对”，使这种候选按现有校验规则被移除，不再造成整个搜索技术失败。
3. 配对不能放在 `memory_open` 共用的结果整形阶段，否则会折叠展开时的同回合邻居。已通过搜索请求的 `query` 条件限定，并由新增测试覆盖。

# 回执：条目读取走已知路径（2026-11-11）

## 改动

`lib/vault-files.js` 的 `read()` 在收到合法的 `context.knownFilePath` 时，
先通过现有 `relativePath()` 规范路径并检查 `.md` 后缀，再用现有
`readFile()` 读取。只有文件存在、frontmatter 可解析且 `samePermalink()`
验明身份时才直接返回；缺失、错文件、越界、非法路径或 frontmatter 不支持
都回退到原 `resolveNote()`。`resolveNote()`、返回格式和权限检查均未改动。

改动后的完整 `read()`：

```js
async read(identifier,context){
  contextCheck(context);
  const known=typeof context?.knownFilePath==='string'
    ?relativePath(context.knownFilePath,project)
    :null;
  if(known?.toLowerCase().endsWith('.md')){
    try{
      const note=await readFile(root,known,project);
      if(note&&samePermalink(note.permalink,identifier,project)){
        contextCheck(context);
        return note;
      }
    }catch(error){
      if(error.code!==BACKEND_ERROR&&error.code!==FRONTMATTER_ERROR)throw error;
    }
  }
  const note=await resolveNote(root,project,identifier);
  contextCheck(context);
  return note;
},
```

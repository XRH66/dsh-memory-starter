## 6. 发现

1. rc.3 的 `tools.restrict` 实机边界成立：关闭记忆后，实际发送给模型的工具列表立即从 36 个降到 31 个，`memory_*` 和 `dafeiyu_records` 等全部消失。任务单最关心的兼容性结论通过。

2. 仅全文、无向量时，“我的猫叫什么？”不能从“我养了一只叫豆包的橘猫”这条事实原话自动预取。索引稳定后预取能命中更早的同名问句，但不会取出含“豆包”的事实句。相关层：

   - `lib/memory-query.js` 的 `prefetchMessage()` 调用原话搜索并经过 `selectPrefetch()`；
   - `lib/memory-query.js` 的 `isAssistantOriginal()` 会跳过助手原话；
   - 默认 `prefetchMinLexical: 0.6` 会拒绝词法重合不足的用户原话；
   - `lib/raw-rag/lexical.js` 将完整问句拆成中文二元词并依赖主语锚点。

   本次正确答案来自 `memory-handoff-context`，不是来自含事实的自动预取。是否把短期接续算作任务单里的“检索到”，或者是否要求向量、重排或预取排序修复，需要 Claude 决定。

3. 会话必须带 `workspaceId` 创建后才会立即进入 rc.3 的 `workspace.json` 索引；不带工作区创建的空白会话虽然能被 `session/list` 看到，但立刻调用设置页绑定会报“请选择此 DSH 实例中未归档的普通会话”。带上隔离工作区后绑定立即成功。此项是实机操作方式差异，未改代码。

4. 验证命令通过 PowerShell 管道传中文时会被旧代码页转成问号；本轮最终使用 `\u` 转义完成有效中文验证。该问题不影响产品内 WEB 输入，不应归因为插件缺陷。

## 发布导出

新增 `npm run release:check` 和 `--validate-only`：

- 白名单必须是规范化仓库相对路径，不能重复、越界、包含链接或指向本地／依赖目录；
- 每个白名单文件必须被 Git 跟踪；
- `lib/`、`scripts/`、`test/` 下的跟踪代码必须进入白名单，当前无排除项；
- 导出到系统临时目录后，使用临时 npm 缓存、用户配置和 HOME／APPDATA／TEMP；
- 清除 Git、SSH、代理和常见凭据类环境注入，只允许 HTTPS；
- 导出依赖安装禁用 npm 生命周期脚本；
- 在导出目录运行全量测试、发布隐私和链接检查；
- 成功与子步骤失败都会清理临时目录。

当前实测：

- 白名单 215 个文件；
- 跟踪代码文件 186 个；
- 导出目录全量 `723 / 723`；
- 隐私检查 215 个文件、违规 0；
- 链接检查 46 个、错误 0；
- 直接执行脚本和使用 `npm run release:check` 均通过 Windows 实测；
- 用伪 HOME、APPDATA、CODEX_HOME、带凭据代理、恶意 Git 配置、合法 npm registry 错误值和禁用 SSH 的环境运行，仍通过；
- 用伪 npm 强制安装步骤失败，临时导出目录已实际删除。

- **认证代理**：发布检查按设计清空代理；必须依赖认证代理访问 GitHub／npm 的环境会失败。

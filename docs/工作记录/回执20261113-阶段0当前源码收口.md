- 根因：`downloadOnly` 会创建隔离 Python 并写安装回执，但清单检查只读取当前、待切换和历史配置；找不到后重新探测默认 Python，因而误判未安装。
- 修复：清单检查从当前记忆库的安装回执目录读取候选，按时间和回执名稳定排序，再用现有 `inspectSelectedInstallation` 复核模型、文件、Python 包和隔离解释器。
- 损坏、超限、模型不符或运行环境失效的回执会被跳过，不影响其他候选。
- 返回给界面的设置仍只包含既有路径字段，不暴露凭据。

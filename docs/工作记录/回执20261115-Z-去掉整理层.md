## 兼容处理

- **旧配置**：`autoCapture`、`organizerReasoningEffort`、`captureProvider`、`captureModel`、`captureTargetMode` 等旧字段不再进入运行时配置；读取时不报错，插件可正常启动。旧 JSON 中的字段不主动删除，后续其他设置保存也不必再写回这些字段。
- **首次配置**：只要求独立记忆目录和聊天选择，不再要求整理服务、整理模型或整理缓存。默认生成配置不再写 `memory.captureProvider`/`memory.captureModel`。
- **旧向量库**：已有条目文档/向量不会被主动破坏或重编码；新文档枚举跳过带 `memory_entry_id` 的条目，查询端忽略旧条目命中。测试覆盖了打开含旧条目向量的库、继续准备时不重编原话。
- **旧原话库**：`RawMemoryStore` 不再创建 `MemoryEntryIndex` 或暴露 `store.entries`；旧库里的 `entries` 表原样保留、不读取，打开和原话读写正常。

## 选文件夹能力

- 客户端插件仍只把 `slots` 声明为必需注入；`uiWorkspace` 通过 `ctx.get('uiWorkspace')` 和可选 `ctx.inject(['uiWorkspace'], ...)` 获取，不阻塞设置页加载。
- 拿不到 `uiWorkspace` 时隐藏“选择文件夹…”按钮，只保留路径输入框，页面不报错。
- 有服务时先调用 `pickDirectory()`：
  - 返回字符串：回填路径；
  - 返回 `null`：视为用户取消，不报错、不改路径；
  - 抛错：进入内置浏览回退。
- 浏览回退使用同一个 `uiWorkspace.listDirectory()` / `createDirectory()`，显示面包屑、子文件夹、新建子文件夹、选择当前文件夹；列表不可读时保留手动输入。
- 实机使用原生窗口，窗口标题为 `Select Workspace Directory`；自动化只确认窗口出现后按 Esc 取消。

## 位置检查接口

- 新增 `POST /api/basic-memory-bootstrap/location`，只读检查，不创建目录、不写 marker。
- 响应外层 `ok:true` 表示请求成功；位置是否可用由单独的 `usable` 字段表达，避免业务状态覆盖 HTTP/JSON 成功状态。
- 状态清单：
  - `missing`：不存在，可新建；
  - `empty`：空文件夹，可直接使用；
  - `initialized`：已有本插件初始化记录且 `vault` 有效，可接着用；
  - `not-empty`：有其他文件，或初始化记录不完整/无效，不能直接用；附建议子目录；
  - `overlap`：与现有个人库、群目录或旧 Vault 重叠；
  - `invalid`：不是绝对路径、不是文件夹或其他路径错误；
  - `linked`：路径本身是链接，或真实路径与填写路径不一致；
  - `unwritable`：当前账户没有写入权限。
- 检查与创建共用 `validateNewMemoryLocation`、`validateExistingMemoryDirectory`；检查另外先做 `lstat`、`realpath` 和 `access(W_OK)`，创建时初始化器会再按同一规则复核。
- 自动化用不存在路径检查后确认目录仍不存在，随后同一路径可成功建库。

## 同意与“只执行一次”

- `activation.json` 的 `consent` 写入：
  - `sessionIds`：第 2 步明确勾选的聊天；
  - `autoEnableNewSessions`：第 2 步明确选择的“新对话自动”。
- 旧 `dshSessionIds` 不进入 `consent`。
- 首次启动成功时保存配置，并对当前已经 live 的选中聊天调用 `sessionMemory.set(id, true)`；尚未 live 的聊天保存在 `consentPendingSessionIds`，不伪造授权。
- 每个待执行聊天在 `agent/created` 真正出现时，通过同一个 `sessionMemory.set()` 路径开启；成功后从启用记录移除。
- 成功记录写 `consentAppliedAt`。
- 记录 `firstRunExistingSessionIds`，首次启用时已经存在的聊天下次不能冒充“新对话”；因此未勾选的旧空聊天不会因首次打开而触发自动开启。
- 后续重启只读取 active 记录和剩余待执行集合。已执行完的选中聊天不再自动开启；实机手动关闭后重启，仍保持关闭。
- 启动失败时不执行未 live 的聊天；已 live 的部分有回滚路径。

## 第 4 步完成判断

- 云端接口：已选模型、接口地址、模型名称，并有保存的密钥或有效密钥环境变量。
- 本地模型：有安装回执，或运行后端已 prepared，或该模型所需文件路径已完整填写。
- 用户点过“先跳过”也算完成。

## 实机中发现并修复的问题

1. 位置检查最初让业务字段 `ok:false` 覆盖了接口成功状态，页面把“其他文件”误显示成“位置检查失败”。现拆成外层 `ok` 与业务 `usable`。
2. DSH 的聊天在未打开时不在 live session store；首次启动无法直接调用 `sessionMemory.set()`。现持久化待执行聊天，第一次 `agent/created` 时通过同一路径开启，并写回剩余集合。
3. 首次启用时已有的空聊天会在第一次打开时被误认为“新对话”。现持久化 `firstRunExistingSessionIds`，自动开启只作用于启用后新出现的聊天。

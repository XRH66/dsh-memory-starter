## 明确行为结果

### 1. `sessionMemory:false` 启动拒绝

`lib/bundle-entry.js` 与 `lib/platform-host.js` 在启动最前面检查：

```text
不再支持不用对话开关的运行方式，请去掉 sessionMemory:false
```

测试加入 `test/platform-host.test.js`，覆盖入口在读取目录和模型配置前直接拒绝。

### 2. 没有整理模型时不写旧格式

旧维护器及其测试整体删除。新增
`test/portable-session-memory.test.js` 用例：

- 不提供 `stream` 整理模型；
- 开启会话并提交一轮双方原话；
- 原文仍保存两条；
- `pipeline.enabled === false`；
- Vault 内没有新增任何 Markdown 文件。

整理流水线正常启用时，原有八轮合批、提交、向量通知和设置页行为继续由完整测试保护。

### 3. 旧“恢复旧任务”

复核结论：旧恢复任务只由旧整理器写入。

- `recoveryStore.save` 只出现在 S2 起点 `lib/worker.js:154` 的 `maintainIndexes` 提交路径；
- 当前 `memory-pipeline` 自己有 durable batch 状态，不使用 `recoveryStore` 的 `pending/jobs/indexMaintenance`；
- `observeLocalFacts` 也只在旧 worker 的 `drain` 路径调用。

因此没有触发“停下”条件。设置页按钮、HTTP 动作、`runMemoryRuntime` 分支、`resumeLegacyRecovery` 和 `maxAutomaticFailures` 已删除。已有 `recovery.json` 和旧会话任务文件不删除；`createRecoveryStore` 只读取并写回自身通用状态，旧任务字段保持不透明。

### 4. 旧近期缓存

`createRecentConversationStore`、lazy store、`recent-v1` 消费者、`recentStore` 参数和 `recentContextTokens` 已删除。

对话开关模式保留的行为没有减少：

- 原文仍保存到 SQLite；
- 文本投影仍完成；
- handoff 仍只取样已有第一页；
- `recent-original-stats.json` 仍只记录统计，不记录正文、会话或查询；
- 旧缓存文件路径函数保留用于兼容断言，但产品不再创建或读取该缓存。

### 5. 纯净模式门控

`pure-gate.js` 和 `personal-access.js` 整文件删除。对话开关模式的人设、自我档案和工具过滤继续调用 `sessionMemory.check`；工具权限和原文授权测试保持通过。

### 6. 防删除守卫

`delete-guard.js` 已删除，未触发停下条件：

- `personal-runtime.js` 只向 `createBridge` 提供本地工具桩，不再连接或自动挂载 Basic Memory；
- `platform-host.js` 对 `mcp__basic_memory__*` 仍执行会话工具隐藏；开启和关闭记忆时都由 `sessionMemory.check` 决定，宿主若提供残留工具也不会绕过当前会话门；
- 仓库限定范围检索没有发现插件自动安装或启动 Basic Memory。

### 7. Q4：旧笔记 Basic Memory 回退

- 生产入口 `createPersonalMemoryRuntime` 必填绝对记忆库目录，并固定写入 `vaultPath=directory/vault`，所以 `localLegacy` 不会因为缺少记忆库目录而缺失。
- 对话开关模式下，条目服务、迁移和旧笔记目录均为同一 Vault 的本地能力。
- `entries.search` 由 `createMemoryEntryAccess.forGrant` 稳定提供；旧回退只可能在测试桩中出现，因此删除回退而不是保留产品分支。
- `localLegacy` 目录不存在或没有可读旧目录时，legacy 通道返回 `state:'unavailable'`，不再调用 `noteSearch` / Basic Memory。
- 旧笔记 `legacyRecord` 仍使用本地校验和与来源状态；`memory_open` 改为用 `readVaultNote` 读取已登记的本地文件。
- `lib/legacy-notes.js` 和 `lib/legacy-import.js` 未删。
